# options

## Overview

Enumerations that tests take as options, each translating to the name its backing SciPy function expects where it has one.

## Components

| Component | Description |
|-----------|-------------|
| [alternative.py](./alternative.py) | `Alternative`, the alternative hypothesis. |
| [center.py](./center.py) | `Center`, the center of the deviations in tests of equal variances. |
| [divergence_statistic.py](./divergence_statistic.py) | `DivergenceStatistic`, Pearson's chi-square or the G statistic. |
| [mcnemar_variant.py](./mcnemar_variant.py) | `McNemarVariant`, the reference distribution of McNemar's test. |
